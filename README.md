# 🏛️ วัฒนธรรมลพบุรี - Cyberpunk Catalog

เว็บไซต์แคตตาล็อกวัฒนธรรมลพบุรีในธีมไซเบอร์พังก์ พร้อมโมเดล 3D และฟีเจอร์ Interactive

## ✨ ฟีเจอร์หลัก

### 🎮 เกมส์และกิจกรรม
- **เกมส์จับคู่วัฒนธรรมลพบุรี**: จับคู่วัฒนธรรมให้ถูกต้อง
- **Quiz เกี่ยวกับลพบุรี**: ทดสอบความรู้เกี่ยวกับลพบุรี

### 🌍 360° View
- ดูสถานที่จริงผ่าน Google Street View
- เชื่อมต่อกับ Google Maps API

### 📚 วัฒนธรรมที่เกี่ยวข้อง
- ประวัติศาสตร์ที่เชื่อมโยงกัน
- งานเทศกาลที่เกี่ยวข้อง
- ลิงก์ไปยังวัฒนธรรมอื่นๆ

### 🎨 3D Models
- โมเดล 3D ของวัฒนธรรมลพบุรี
- รองรับไฟล์ GLB จาก tripo3d.ai
- ระบบดาวน์โหลดโมเดล

## 🚀 การติดตั้ง

1. **Clone repository**
```bash
git clone [repository-url]
cd eglisgh
```

2. **รันเว็บเซิร์ฟเวอร์**
```bash
python -m http.server 8000
```

3. **เปิดเบราว์เซอร์**
```
http://localhost:8000
```

## 🔧 การแก้ไขปัญหา

✅ **แก้ไขแล้ว**: เพิ่ม event listeners และฟังก์ชันที่ถูกต้อง

### ปัญหา 2: วัฒนธรรมที่เกี่ยวข้องไม่แสดง
✅ **แก้ไขแล้ว**: เพิ่มการตรวจสอบข้อมูลและแสดงผลที่ถูกต้อง

### ปัญหา 3: 360° View ไม่ตรงตำแหน่ง
🔧 **วิธีแก้ไข**: แก้ไขพิกัดในไฟล์ `script.js`

## 📍 การปรับแต่งพิกัด 360° View

### วิธีที่ 1: แก้ไขในโค้ด
แก้ไขในไฟล์ `script.js` บรรทัดที่ 760-780:

```javascript
const locations = {
    monkey: { lat: 14.7995, lng: 100.6533, name: "ลิงลพบุรี - ปรางค์สามยอด" },
    "salted-egg": { lat: 14.7995, lng: 100.6533, name: "ตลาดไข่เค็มลพบุรี" },
    chalk: { lat: 14.7995, lng: 100.6533, name: "แหล่งดินสอพองลพบุรี" },
    prang: { lat: 14.7995, lng: 100.6533, name: "ปรางค์สามยอด" },
    dam: { lat: 14.7995, lng: 100.6533, name: "เขื่อนป่าสักชลสิทธิ์" },
    mountain: { lat: 14.7995, lng: 100.6533, name: "เขาวงพระจันทร์" }
};
```

### วิธีที่ 2: หาพิกัดจาก Google Maps
1. เปิด Google Maps
2. ค้นหาสถานที่ที่ต้องการ
3. คลิกขวาที่ตำแหน่ง → "What's here?"
4. คัดลอกพิกัด (latitude, longitude)

### พิกัดที่แนะนำ:
- **ปรางค์สามยอด**: 14.7995, 100.6533
- **เขื่อนป่าสักชลสิทธิ์**: 14.7995, 100.6533
- **เขาวงพระจันทร์**: 14.7995, 100.6533

## 🎯 วิธีการใช้งาน

### เกมส์จับคู่วัฒนธรรม
1. คลิกปุ่ม "🎮 เกมส์และกิจกรรม"
2. เลือก "เกมส์จับคู่วัฒนธรรม"
3. คลิกการ์ดเพื่อพลิกและจับคู่

### Quiz ลพบุรี
1. คลิกปุ่ม "🎮 เกมส์และกิจกรรม"
2. เลือก "Quiz ลพบุรี"
3. ตอบคำถามและดูผลลัพธ์

### 360° View
1. คลิกปุ่ม "🌍 ดู 360° View"
2. ระบบจะเปิด Google Street View ในแท็บใหม่
3. หากไม่พบ Street View ให้ค้นหาใน Google Maps

### วัฒนธรรมที่เกี่ยวข้อง
1. คลิกปุ่ม "📚 วัฒนธรรมที่เกี่ยวข้อง"
2. อ่านประวัติศาสตร์และงานเทศกาล
3. ใช้ปุ่มนำทางเพื่อกลับไปหน้าหลัก
