# วัฒนธรรมลพบุรี - Cyberpunk Catalog

เว็บไซต์ catalog แสดงวัฒนธรรมและสถานที่สำคัญของจังหวัดลพบุรีในธีม cyberpunk ที่เท่และสวยงาม

## ✨ คุณสมบัติ

- **ธีม Cyberpunk**: ดีไซน์ที่เท่และทันสมัยด้วยสีสัน neon และเอฟเฟกต์แสง
- **Catalog แบบ Interactive**: แสดงรายการวัฒนธรรมลพบุรี 6 รายการ
- **โมเดล 3D**: แต่ละรายการมีโมเดล 3D ที่สามารถหมุนและซูมได้
- **Responsive Design**: รองรับการแสดงผลบนอุปกรณ์ทุกขนาด
- **Particle Effects**: เอฟเฟกต์อนุภาคที่เคลื่อนไหวตลอดเวลา

## 🏛️ รายการวัฒนธรรมที่แสดง

1. **ลิงลพบุรี** - ลิงแสมที่อาศัยในเมืองลพบุรี
2. **ไข่เค็มลพบุรี** - ผลิตภัณฑ์ที่มีชื่อเสียงของจังหวัด
3. **ดินสอพอง** - ผลิตภัณฑ์คุณภาพดีจากลพบุรี
4. **ปรางค์สามยอด** - โบราณสถานสำคัญ
5. **เขื่อนป่าสักชลสิทธิ์** - เขื่อนใหญ่ที่สุดในประเทศไทย
6. **เขาจีนแล** - ภูเขาสูงที่มีความสำคัญทางประวัติศาสตร์

## 🚀 การใช้งาน

1. เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์
2. เลือกรายการที่ต้องการดูจาก catalog
3. คลิกที่ "ดูโมเดล 3D" เพื่อเปิด modal
4. ใช้เมาส์เพื่อ:
   - คลิกและลากเพื่อหมุนโมเดล
   - ใช้ scroll wheel เพื่อซูมเข้า/ออก
5. กด ESC หรือคลิก X เพื่อปิด modal

## 🛠️ เทคโนโลยีที่ใช้

- **HTML5**: โครงสร้างเว็บไซต์

- **Three.js**: การสร้างโมเดล 3D

## 🌟 เอฟเฟกต์พิเศษ

- **Glitch Effect**: เอฟเฟกต์ข้อความที่แตกแยก
- **Grid Overlay**: พื้นหลังแบบตารางที่เคลื่อนไหว
- **Scanlines**: เส้นสแกนที่เคลื่อนไหว
- **Particle System**: อนุภาคที่ลอยขึ้น
- **Hover Effects**: เอฟเฟกต์เมื่อ hover
- **Modal Animation**: การเคลื่อนไหวของ modal

## 🎯 การควบคุมโมเดล 3D

- **หมุน**: คลิกและลากเมาส์
- **ซูม**: ใช้ scroll wheel
- **Pan**: คลิกขวาและลาก (ถ้ารองรับ)
