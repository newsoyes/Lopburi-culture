# โฟลเดอร์ Models

โฟลเดอร์นี้สำหรับเก็บไฟล์โมเดล 3D ในรูปแบบ GLB ที่สร้างจาก www.tripo3d.ai

## 📁 โครงสร้างไฟล์ที่แนะนำ

```
models/
├── monkey.glb          # โมเดลลิงลพบุรี
├── salted-egg.glb      # โมเดลไข่เค็ม
├── chalk.glb           # โมเดลดินสอพอง
├── prang.glb           # โมเดลปรางค์สามยอด
├── dam.glb             # โมเดลเขื่อนป่าสัก
├── mountain.glb        # โมเดลเขาจีนแล
└── README.md           # ไฟล์นี้
```

## 🎯 วิธีใช้งาน

1. **สร้างโมเดล 3D จาก tripo3d.ai**
   - ไปที่ www.tripo3d.ai
   - สร้างโมเดล 3D ตามที่ต้องการ
   - ดาวน์โหลดไฟล์ในรูปแบบ GLB

2. **วางไฟล์ในโฟลเดอร์นี้**
   - เปลี่ยนชื่อไฟล์ให้ตรงกับที่กำหนดไว้
   - หรือแก้ไขชื่อไฟล์ใน `script.js`

3. **เปิดใช้งานในเว็บไซต์**
   - แก้ไข `modelType` ใน `script.js` จาก "builtin" เป็น "glb"
   - เพิ่มเส้นทางไฟล์ใน `glbModels` object

## 🔧 ตัวอย่างการตั้งค่า

ในไฟล์ `script.js`:

```javascript
// เปลี่ยน modelType เป็น "glb"
monkey: {
    title: "ลิงลพบุรี",
    description: "...",
    modelType: "glb"  // เปลี่ยนจาก "builtin" เป็น "glb"
}

// เพิ่มเส้นทางไฟล์
const glbModels = {
    monkey: "models/monkey.glb",
    "salted-egg": "models/salted-egg.glb",
    // ... เพิ่มไฟล์อื่นๆ
};
```

## 📝 หมายเหตุ

- ไฟล์ GLB ควรมีขนาดไม่เกิน 10MB เพื่อการโหลดที่เร็ว
- ตรวจสอบให้แน่ใจว่าไฟล์ GLB มี texture และ material ที่สมบูรณ์
- หากไฟล์มี animation จะแสดงผลอัตโนมัติ
- รองรับไฟล์ GLB, GLTF และไฟล์ 3D อื่นๆ ที่ Three.js รองรับ

## 🎨 เคล็ดลับการสร้างโมเดล

1. **ขนาดที่เหมาะสม**: สร้างโมเดลให้มีขนาดที่เหมาะสม (ไม่ใหญ่หรือเล็กเกินไป)
2. **Texture ที่ชัดเจน**: ใช้ texture ที่มีความละเอียดเหมาะสม
3. **Animation**: เพิ่ม animation เพื่อให้โมเดลดูมีชีวิตชีวา
4. **Optimization**: ลดจำนวน polygon หากไม่จำเป็น
